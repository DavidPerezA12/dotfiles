# nvim

## Descripción

Este repositorio contiene mi configuración personalizada de Neovim. Neovim es una versión moderna y mejorada del popular editor de texto Vim, diseñado para ser más extensible y flexible.

## Contenido

- **Archivos de configuración:** Incluye archivos de configuración específicos para Neovim que personalizan su comportamiento y apariencia según las preferencias de David Pérez.

- **Plugins:** Se incluye un archivo de configuración para el gestor de plugins de Neovim, como [vim-plug](https://github.com/junegunn/vim-plug), que permite instalar y gestionar plugins fácilmente.
